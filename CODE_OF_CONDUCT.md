# Code of conduct

Know Your Ballot is a non-partisan civic project. Everyone is welcome to use it and to help build it, whatever they believe or vote.

- Be kind and assume good faith. Disagree about code and sources, not about people.
- Keep politics out of the project. We publish what official sources and the candidates themselves say, never our own opinion of a candidate, party or measure. Pull requests and issues that argue for or against a candidate are closed.
- No harassment, no personal attacks, no sharing of anyone's private information.
- Mistakes about a real person are urgent. If you see one, open an issue with the "Wrong information" template; if you caused one, say so and help fix it.

Maintainers may edit, hide or close anything that breaks these rules, and may block repeat offenders. To report a problem privately, email chn.govbot@gmail.com.

This code of conduct is adapted from the Contributor Covenant, version 2.1.
