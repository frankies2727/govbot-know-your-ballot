# Security

Know Your Ballot runs entirely in the browser. It stores a reader's address and picks only in their own browser's `localStorage`, sends the address to a public geocoder to find their districts, and nothing else leaves the device. There are no accounts and no server of ours.

If you find a way that changes (a script that can read another reader's picks, a way to inject content into a card, a dependency with a known problem), please email **chn.govbot@gmail.com** rather than opening a public issue, so it can be fixed before it is described. You will hear back within a few days.

Wrong information about a candidate or judge is not a security problem; report that with the "Report a mistake" link on the card, or the wrong-information issue template.
